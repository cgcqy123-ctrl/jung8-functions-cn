# 荣格八维人格测验 · 量表版（中国情境版）

**152 句中国日常陈述，每句按「有多像我」选一个同意程度；算出八个功能的强度，再按荣格的结构判定类型。**

> ⚡ **精简版**（80 题 · 约 13 分钟）：<https://cgcqy123-ctrl.github.io/jung8-functions-cn/lite.html>

## 它是什么

- **测什么**：荣格《心理类型》（1921）里的**八种功能态度**——感觉、直觉、思维、情感，各有内倾、外倾两个朝向。
- **怎么答**：7 点同意度（−3 到 +3），一句话一道题，共 152 题。
- **怎么判**：八维各得 0–100 分 → 个人内中心化 → 主导 → 辅助（另一类功能 × 相反态度两个候选里取高者）→ 第三、劣势按结构推出 → 四字母只作换算层。
- **输出**：八维强度条、功能栈、置信度（领先幅度 + 奇偶一致性）、候选类型前三、类型画像、可复制的 AI 分析提示词。

## 它不是什么

- 不是医学诊断，测不出抑郁、焦虑、注意力问题。
- 不是招聘或筛选工具。
- 没有常模、没有信效度检验——分数只能和你自己的八个功能比，不能和「全国样本」比。
- 四字母不是判决；J/P 尤其不是「计划性强 / 散漫」（手册 5.7 解释了为什么）。

## 和常见四字母网测差在哪

| | 常见四字母网测 | 这一版 |
|---|---|---|
| 理论 | 四个维度各自相减 | 八种功能态度，先定主导再定辅助 |
| 题目 | 通用场景（派对、公路旅行） | 十个生活域：家庭、职场、学习、社交、消费、冲突、兴趣、信息、亲密、身体 |
| 判定 | 四个开关拼字母 | 功能栈是判定本身，四字母是换算 |
| 结果 | 类型 + 百分比条 | 八维绝对分 + 相对分 + 功能栈 + 置信度 + 候选类型 |

## 题目怎么来的

**152 = 8 × 19。** 八维要等权，题数必须是 8 的倍数；每个功能 19 题、其中 6 题反向（约三分之一），十个生活域的配额每个功能都一样：

`家庭 3 · 职场 3 · 学习 2 · 社交 2 · 消费 2 · 冲突 2 · 兴趣 2 · 信息 1 · 亲密 1 · 身体 1`

写题的红线（详见 `likert8/SPEC.md`）：只写行为与注意力的落点、不写自我评价、不用频率词、不用刻板印象、同一场景在不同功能下必须写出不同的注意力落点。

**题目全部原创**，没有复制、翻译或改写任何商业量表的题干。作答形式（陈述句 + 同意度 + 百分比条）是通用的交互形式。

## 怎么算（八步）

| 步 | 做什么 |
|---|---|
| 1 | 七档选项对应 −3 … +3，「中立」是 0 |
| 2 | 反向题翻号（该题分数取反） |
| 3 | 每个功能 19 题求均值 m，映射 `(m+3)÷6×100` 得 0–100 绝对分 |
| 4 | 减去个人八维均值＝相对分（题数等权，所以这个减法公平），用来判类型 |
| 5 | 主导＝相对分最高；辅助＝「另一类功能 × 相反态度」两个候选里较高者 |
| 6 | 第三＝与辅助同类、态度同主导；劣势＝与主导同类、功能对立、态度相反（对照表见手册 5.6） |
| 7 | 四字母：E/I 看主导朝向；S/N、T/F 由主导与辅助按类分配；J/P 看「对外展示的那个功能」 |
| 8 | 置信度：领先幅度（前两名相对分差）+ 奇偶一致性（题目奇偶两半八维排序的斯皮尔曼相关） |

## 结果怎么读

**先看形状，再看最高的那个。** 主导与劣势是一对（强项拿什么当代价）、辅助与第三是一对（被低估的那只手）、同类的 Fe/Fi、Se/Si、Ne/Ni、Te/Ti 对照着看最能看出自己的侧重。

**分数低 ≠ 能力差。** 低分说的是使用频率，不是水平。

**置信度低不等于结果没用**，它等于「这次作答不足以下结论」，隔一周重做比研究这个结果划算。

## 本地运行

需要 Python 3.10+（`python-docx`），只有网页测试才需要 Node.js。

```bash
python likert8/check_items.py likert8/items_Te.json   # 单功能自检
python likert8/merge.py                               # 合并成 152 题
python likert8/check_all.py                           # 全量校验
python likert8/make_lite.py                           # 抽取精简版 80 题
python likert8/check_lite.py                          # 精简版校验
python likert8/build.py                               # 生成 index.html 与 lite.html
python likert8/build_docx.py                          # 生成手册 docx
node likert8/dom_test.js                              # 网页冒烟测试
```
