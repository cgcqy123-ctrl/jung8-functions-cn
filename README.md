# 荣格八维人格测验 · 中国情境版

一份按荣格《心理类型》（1921）的**八种功能态度**重写的中文自测工具。

**作答形式**：152 句陈述，每句按「有多像我」选 7 档同意度（强烈不同意 → 强烈同意）。
**判定方式**：不用「四个维度各自相加」，而是先算出八个功能的强度，再定主导、定辅助，第三与劣势按结构推出，四字母只作为对照层。

> 📖 **在线试用**（152 题 · 约 25 分钟）：<https://cgcqy123-ctrl.github.io/jung8-functions-cn/>
>
> 📄 **旧版存档**：[`荣格八维人格测验-中国情境版.docx`](荣格八维人格测验-中国情境版.docx) 是 64 题「二选一 + 强度」那一版的纸笔手册，**已停止使用**，留在仓库里只作对照。

## 为什么还要做一版

常见的四字母网测（以 16Personalities 为例）在中文使用者身上容易失真的地方，大致三层：

1. **情境错位。** 题目默认的生活是派对、长途自驾、社区活动、开放式办公室；而多数人的日常是家族群、酒桌、周报、合租、催婚、学区房。场景对不上，填的是"我觉得我应该是哪种人"。
2. **理论错位。** 荣格讲的是八种功能态度如何组合成类型；四字母体系把它压成四个独立开关，两边相减。它测到的更像自我标签，而不是"你先注意什么、凭什么下判断"。
3. **结果错位。** 写得越像"说的就是我"，越可能是巴纳姆效应。好的结果应该让人有点不舒服——它得指出你不擅长什么、压力下会变成什么样。

## 这版做了什么

- **回到荣格**：测八种功能态度，先定主导、再定辅助，劣势按结构推出；四字母只做换算层。
- **换掉情境**：152 句陈述覆盖十个生活域——家庭亲戚、职场办公、学习考试、社交人情、消费生活、冲突矛盾、兴趣娱乐、信息媒体、亲密关系、身体健康。
- **题数等权**：每个功能 19 题、其中 6 题反向，八个功能题数完全相同，所以 0–100 的分数可以直接互相比较。
- **判主导用中心化**：先算绝对分，再减去个人八维均值来判主导——避免「整体爱打高分」的人被误判。
- **结果可核对**：给出八维分数、功能栈、置信度（领先幅度 + 奇偶一致性）、候选类型前三，以及与主判不一致时的提示。
- **结果能直接交给 AI**：结果页可一键复制「AI 分析提示词」——里面已写好你的分数、计分口径、理论边界，以及要它按什么顺序分析、哪些事不许干；也支持下载成 `.txt`。把手册一起上传效果更好。

## 怎么判（一句话版）

152 题 = 8 个功能 × 19 题。每个功能恰好 19 题、6 题反向，八个功能题数等权；每题 7 点（−3…+3），反向题翻号。

| 步骤 | 规则 |
|---|---|
| 1. 计分 | 每题 7 点记 −3…+3，加给该题所属的功能；反向题翻号；八维各自取均值映射到 0–100 |
| 1b. 中心化 | 判主导前先减去个人八维均值（题数等权，所以均值可比），抵消整体偏高/偏低的作答风格 |
| 2. 主导 | 八维得分最高者 = 主导功能态度 → 决定**荣格类型**（八型之一） |
| 3. 辅助 | 在「另一类功能 × 相反态度」的两个候选里取高分者 |
| 4. 第三 / 劣势 | 第三 = 与辅助同类、态度同主导；劣势 = 与主导同类、态度相反 |
| 5. 四字母 | E/I 看主导态度；S/N 与 T/F 由主导与辅助按类分配；J/P 看对外展示的那个功能属判断还是知觉 |

**关于 J/P**：它不是荣格的概念，是迈尔斯为了方便对应外部行为而加的操作化约定。所以 **J ≠ 计划性强，P ≠ 散漫**——文档第四章 4.5 专门讲了这一点。

## 本地运行 / 重新生成

需要 Python 3.10+ 与 Node.js（只有 `node` 相关的校验才需要）。

```bash
python tools/check_items.py data/items_a.json data/items_b.json --merged  # 题目配平/方向/字数
python tools/check_types.py                                              # 类型数据与功能栈
python tools/score.py --selftest                                         # 16 型往返 + 恒等式

python likert8/check_items.py likert8/items_Te.json   # 单个功能 19 题自检
python likert8/merge.py                              # 合并成 152 题
python likert8/check_all.py                          # 全量校验（等权/反向/域配额/去重）
python likert8/build.py                              # 重新生成 index.html
node likert8/dom_test.js                             # 网页冒烟测试
```

## 已知局限（请务必读完）

- **没有常模，也没有经过独立样本的信效度检验。** 它不是临床量表，不能诊断，也不能预测学业、职业、婚姻结果。
- **自评 + 强制选择**只能减少、不能消除社会赞许偏差。类型边界上的人，结果会随状态漂移。
- **八维分数是相对排名，不是能力分**，八个分数相加恒为 0，不能跨人比较。
- **类型是假设，不是结论。** 检验方法：拿它解释你最近三次真实的反应；解释得通就留着，解释不通就丢掉一部分。
- 本项目是个人学习与写作产物，与荣格、迈尔斯、NERIS 及任何 MBTI 相关机构无关；文中提到的 16Personalities 仅作对照样本，其自报数据不作为效度证据。
