# 第六章 十六型画像

这一章把八种功能态度两两组合，落到十六个四字母类型上。十五分钟读完会发现：每篇画像里最像你的，往往不是"优势"那几行，而是"压力下的样子"。

先说清两件事。

**第一，十六型是荣格八型的细化，不是另一套理论。** 每一个四字母类型背后都是一个确定的功能栈。如果你只打算记一样东西，记功能栈，比记四个字母有用得多——字母是路标，功能栈才是路。

**第二，四字母里唯一不属于荣格的，是 J/P。** 第四章 4.5 已经说明过：J/P 是迈尔斯加的操作化约定，指的是"你对外展示的那个功能是判断性的还是知觉性的"。所以看到"J 型喜欢做计划""P 型讨厌被安排"这类说法，可以直接跳过——那不是荣格的意思，也常常不准。

每篇画像的结构是固定的：核心运作方式 → 职场 → 家庭与亲戚 → 亲密关系 → 优势 → 盲区 → 压力下的样子 → 可以怎么长 → 容易和谁混。
