# 16 型风格量表（中国情境版）· 设计规格

> 这是主测验（荣格八维、强制二选一）之外的**第二个模块**。
> 目标：保留 16personalities 那套“陈述句 + 7 点同意度 + 五个维度百分比”的作答体验，
> 但题目**全部原创重写**，场景换成中国人的日常。
>
> **不做的事**：不抓取、不翻译、不复刻对方题库的任何一道题。结构与作答形式是公开的，
> 题目文本是版权内容——这一条不越线。

---

## 1. 与主测验的分工

| | 主测验（荣格八维） | 本模块（16 型风格量表） |
|---|---|---|
| 理论 | 荣格《心理类型》八种功能态度 | 五维倾向（E/I、S/N、T/F、J/P、A/T） |
| 题目 | 64 题，每题两个具体反应二选一 + 强度 | 60 题，每句陈述，7 点同意度 |
| 判定 | 先定主导、再定辅助，四字母是换算层 | 五个维度各自算百分比，不推功能栈 |
| 结果 | 功能栈 + 置信度 + 候选类型 | 五个百分比条 + 面向细分 |
| 诚实边界 | 类型是假设 | 这是**倾向强弱**，不是类型；不要当诊断 |

两者结论**不保证一致**，也不该一致：主测验问“你怎么处理信息”，本模块问“你多常这样”。
把两边对照着看，反而能看出自己“想成为的人”和“实际做法”的差。

## 2. 五个维度与 20 个面向（自拟命名）

每个维度 5 个面向，共 **25 个面向**；每个面向 2 题（一正一反），合计 **50 题**。

| 维度 | 两端 | 面向（本模块自拟） |
|---|---|---|
| 心力 Mind | 外倾 E ／ 内倾 I | 社交启动、主动表达、独处恢复、人群耐受、陌生场合 |
| 能量 Energy | 直觉 N ／ 观察 S | 细节留神、想象投入、抽象兴趣、现实焦点、模式与隐喻 |
| 本性 Nature | 情感 F ／ 思维 T | 逻辑优先、情绪感知、冲突直面、取悦倾向、人情与原则 |
| 对策 Tactics | 计划 J ／ 展望 P | 计划性、收尾习惯、临场应变、秩序需求、开放选项 |
| 身份 Identity | 自信 A ／ 起伏 T | 自我肯定、事后反刍、压力反应、完美主义、情绪起伏 |

> 面向名与划分是本模块自己定的，用来把 60 题摊匀、让结果能细看；不宣称与任何商业量表一致。

## 3. 作答与计分

- 每题一句陈述句，7 点：`−3 强烈不同意 / −2 不同意 / −1 有点不同意 / 0 中立 / +1 有点同意 / +2 同意 / +3 强烈同意`
- 反向题（标记 `reverse`）按 +/− 翻转计分。
- 面向分：该面向 2 题（其中一题反向）均值 → 线性映射到 0–100。
- 维度分：该维度 5 个面向共 15 题的均值 → 0–100。
- 维度端点：≥ 50 取正端（E/N/F/J/A），< 50 取负端（I/S/T/P/T）。50 附近 ±3 视为“居中”，结果页提示“这一维你两边都用”。
- 结果页给：五条百分比条 + 每维一句话解释 + 20 个面向的小条（可选展开）+ 与主测验结果的对照提示。

## 4. 出题红线（与主测验一致）

1. 具体到能想象的行为，不写“你是个有创造力的人”这类自我评价。
2. 不写能力题、不写价值判断、不写“应该”。
3. 不出现非中国日常场景（派对、教会、公路旅行）。
4. 不用性别、地域、学历、收入刻板印象。
5. 每个面向两题、一正一反，避免一路“同意”拿高分。
6. 反不反向不重要，重要的是同一面向的两题必须问同一件事的两面，不能一题问频率、一题问态度。

## 5. 数据格式

```json
{
  "meta": { "version": "0.1", "scale": 7, "items": 60 },
  "items": [
    {
      "id": "L01",
      "dim": "Mind",
      "facet": "社交启动",
      "key": "E",
      "reverse": false,
      "text": "一桌人都不熟的时候，你往往是先开口的那个。"
    }
  ]
}
```

`key` 表示“同意这一句 = 偏向哪一端”，`reverse` 只影响计分，不影响文本。

## 6. 交付

- `likert/items.json`：60 题
- `likert/index.html`：单文件作答页（7 点量表、进度、自动计分、结果五条百分比条）

- 结果可复制成 AI 分析提示词（复用主测验那套写法）
