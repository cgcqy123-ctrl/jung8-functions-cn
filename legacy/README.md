# legacy — 已停用的两个版本

这里的东西**不在页面上跑**，留着只为对照与追溯。当前版本在仓库根目录与 `likert8/`。

## 1. `twochoice/` — 64 题「二选一 + 强度」版（v1.x）

- 每题给两个具体反应（A / B），选更像的那个，再选强度 1–4。
- 判定：八维分数相加恒为 0（ipsative），主导取最高分。
- 优点：位置偏差被彻底抵消（同一对功能出正反两题，八维各出现 16 次、8 次在 A 位）。
- 缺点：把「不表态／回避」这条路堵死；题量扩不上去；只能排相对高低，说不出绝对强弱。
- 文件：`items_a/b/c.json`（64 题）、`tools/`（计分、构建、校验、回归测试）、`SPEC-64题二选一.md`、`ch*.md`（手册正文底稿）、`荣格八维测验-64题二选一手册.docx`。

跑它需要把 `tools/` 放回根目录（脚本里按上级目录找 `data/`），因此这里只作存档，不建议直接运行。

## 2. `likert5/` — 50 句五维量表版（v2.0）

- 7 点同意度，25 个面向各 2 题（一正一反），出五个维度百分比（心力 E/I、能量 N/S、本性 T/F、对策 J/P、身份 A/T）。
- 优点：作答轻，约 8 分钟；有 16 型风格的百分比条。
- 缺点：五个维度是四字母体系的口径，不是荣格的功能态度；测的是自我标签倾向。
- 文件：`items.json`、`template.html`、`build.py`、`check_likert.py`、`dom_test.js`、`SPEC.md`。
- 构建输出已改为 `legacy/likert5/index-legacy.html`，**不会覆盖**根目录的 `index.html`。

```bash
python legacy/likert5/build.py        # 生成 index-legacy.html
python legacy/likert5/check_likert.py # 50 题校验
```

## 为什么不用它们了

两版都在解同一个问题：怎样把「荣格的功能态度」变成能答的题。二选一版解决了配平但牺牲了自然度；五维版解决了自然度但丢了理论。当前版本（152 题 · 7 点 · 八维）是把两者的优点拼起来：**用 7 点同意度保住自然度，用「每功能 19 题等权 + 反向题」保住配平，用「先定主导再定辅助」保住理论**。
