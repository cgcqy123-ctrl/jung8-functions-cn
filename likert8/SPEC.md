# 八维量表版（7 点同意度）· 出题规格 v3.0

> 目标：把「选程度」的作答方式与荣格的八种功能态度结合。
> 152 题 = 8 个功能 × 每个 19 题，八维严格等权。
> 题目全部原创，不复制任何商业量表题干。

## 1. 为什么 152 而不是 150

八维要等权，题数必须是 8 的倍数。152 = 8 × 19；150 会让两个功能各少一题，主导功能判定会被题量差影响。

## 2. 八个功能的「认知动作」（写题只写这个动作）

- **Se 外倾感觉**：接住此刻具体、可感的信息并立刻反应。画面：到现场先看先试；对声音、气味、身体状态敏感；临时变动反而来劲。
- **Si 内倾感觉**：把当下拿去和过去的具体经验、身体记忆比对。画面：记得住细节和旧路数；到新地方先找「和以前一样的地方」；按流程才踏实。
- **Ne 外倾直觉**：由一个点发散出多种可能，跨领域连线。画面：脑子里同时开着好几个「如果…会怎样」；看旧东西想到新用法。
- **Ni 内倾直觉**：从材料里收敛出主线、趋势、隐喻。画面：常有整体预感；爱想意义与长期；表达跳跃但都指向一个点。
- **Te 外倾思维**：把外部世界组织成目标、步骤、标准。画面：开口就是「先干什么、谁负责、什么时候交」；爱排优先级。
- **Ti 内倾思维**：在内部拆概念、找前提、验一致性。画面：爱问「这说法成立吗」；对自相矛盾极敏感；喜欢精确定义。
- **Fe 外倾情感**：读气氛、照顾感受、求共识与得体。画面：进门先看谁不高兴；为「大家都好过」调整说法；在意人情分寸。
- **Fi 内倾情感**：校准内在价值——什么对我真的重要、不能妥协。画面：对「违心」极敏感；一套不轻易外说的好恶；认同来自「这符合我是谁」。

## 3. 每个功能 19 题的构成

域配额（每个功能都按这个来，共 19 题）：

| 域 | 题数 |
|---|---|
| 家庭亲戚 | 3 |
| 职场办公 | 3 |
| 学习考试 | 2 |
| 社交人情 | 2 |
| 消费生活 | 2 |
| 冲突矛盾 | 2 |
| 兴趣娱乐 | 2 |
| 信息媒体 | 1 |
| 亲密关系 | 1 |
| 身体健康 | 1 |

正反向：19 题里 **6 题反向**（`reverse: true`）。反向题是把同一件事写成相反的说法，同意它就等于**不**偏这个功能。
例（Te）：正向「接到任务，你先拆成步骤和截止时间」；反向「事情来了就先做，计划等做完再说」。

## 4. 写作红线

1. 只写行为与注意力的落点，不写自我评价（如「你很有洞察力」）。
2. 不写能力题、价值题、「应该」。
3. 不出现非中国日常场景（派对、教会、公路旅行）。
4. 不用性别、地域、学历、收入、职业贵贱的刻板印象。
5. 不用「总是／从不／经常／通常」这类频率词，改写成具体情境。
6. 不同功能的题不能只是换了主语的同一句话；同一功能的 19 题场景必须分散。
7. 文本 10–34 个汉字（不含标点）。
8. 不出现政治敏感、宗教、民族议题。

## 5. 交付格式

每个功能一个文件：`likert8/items_<功能代号>.json`，例如 `likert8/items_Te.json`。
字段固定为 `id`、`fn`、`reverse`、`domain`、`text`：

```json
{
  "fn": "Te",
  "items": [
    {"id": "Te-01", "fn": "Te", "reverse": false, "domain": "职场办公",
     "text": "接到任务，你先拆成步骤和截止时间。"}
  ]
}
```

- `id`：功能代号 + 两位序号（Te-01 … Te-19）
- `reverse`：true / false 布尔值
- `domain`：取自第 3 节的十个域之一

写完自检：`python likert8/check_items.py likert8/items_Te.json`，PASS 才算交付。
文件里不要加注释，不要写别的字段。
