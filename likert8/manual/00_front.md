# 前言

这份手册对应的是**量表版**：152 句陈述，每句按「有多像我」选一个同意程度，最后给出八个功能的强度和一个类型判定。

它和很多人做过的四字母网测不太一样，有两点最好先说清：

**第一，它不是把四个维度各自相加。** 荣格 1921 年在《心理类型》里做的，是把人的心理活动拆成八种「功能态度」——感觉、直觉、思维、情感，各自有内外两个朝向。类型不是四个开关，而是这八个里有几个强、几个弱，强的那两个怎么搭。所以这份测验问的是「你先注意什么、凭什么下判断」，而不是「你更外向还是更内向」。

**第二，它的题目全部取自中国日常。** 家族群、周报、合租的碗、亲戚借钱、被临时点名、体检报告、催婚、学区房——不是派对、公路旅行、社区活动。这不是为了接地气而接地气：场景对不上，人填的就不是「我实际怎么做」，而是「我觉得我应该是哪种人」。

**关于「手册」这个用法。** 如果你打算把结果交给 AI 分析，把这份手册一起给它，比只给分数有用得多——手册里有计分口径、八种功能的定义、以及哪些结论不能下。结果页的 AI 提示词旁边就有下载按钮。

最后说一句实话：它不是诊断，不是招聘标准，也不是命运。152 道题测的是「你多常这样」，而这只是你的一部分。

# 第一章　为什么还要做一版

## 1.1 三层失真

常见的四字母网测（以 16Personalities 为例）在中文使用者身上，容易在三个层面失真。

**情境错位。** 题目默认的生活是派对、长途自驾、社区活动、开放式办公室；而多数人的日常是家族群、酒桌、周报、合租、催婚、照顾老人。场景对不上，作答就变成了自我想象。

**理论错位。** 荣格讲的是八种功能态度如何组合成类型；四字母体系把它压成四个独立开关，两边相减。它测到的更接近自我标签，而不是认知方式。同一个人在不同场合、不同心情下，四个字母很容易来回跳，原因就在这里——**被平均掉的是「哪个功能在主导」，留下的只是行为表层**。

**结果错位。** 写得越像「说的就是我」，越可能是巴纳姆效应。好的结果应该让人有点不舒服：它得指出你不擅长什么、压力下会变成什么样。

## 1.2 这一版做了什么

| | 做法 |
|---|---|
| 理论 | 测八种功能态度，先定主导、再定辅助，第三与劣势按结构推出；四字母只作对照层 |
| 作答 | 152 句陈述，7 点同意度（−3 到 +3），可以分三次做完 |
| 场景 | 十个生活域：家庭亲戚、职场办公、学习考试、社交人情、消费生活、冲突矛盾、兴趣娱乐、信息媒体、亲密关系、身体健康 |
| 配平 | 每个功能 19 题、其中 6 题反向；八维题数完全相等，分数可直接互比 |
| 结果 | 八维绝对分 + 个人内中心化后的相对分 + 功能栈 + 置信度 + 候选类型前三 |

## 1.3 为什么从「二选一」换成「选程度」

这个仓库早先有一版是**强制二选一**：每题给两个具体反应，选更接近的那个，再选强度。它的优点是位置偏差被彻底抵消（同一对功能出正反两题），缺点是：

1. **把「不表态」堵死了。** 有些场景最自然的反应是沉默、回避、不接话，二选一里没有这条路，只能硬挑一个不像的。
2. **题量受限。** 每加一对功能就要出两题，扩到 150 题以上代价很高。
3. **它测的是相对排序**，不是绝对强度——你能知道哪个功能最强，但不知道强到什么程度。

量表版把这三件事都解决了：单句陈述允许「有点同意」这种中间态；每功能 19 题可以横向铺开生活域；绝对分 0–100 能让「我 Se 62 分」这种描述成立。

代价也要讲明白：**自评量表有天生的社会赞许偏差**——大家倾向于把自己答得「更好一点」，整体分数会被抬高。反向题只减少、不消除这个偏差。所以我用「个人内中心化」来判主导：先算绝对分，再减掉你自己的八维均值，这样整体爱打高分的人不会被误判。
