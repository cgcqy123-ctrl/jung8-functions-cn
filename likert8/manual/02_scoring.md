# 第四章　怎么答

## 4.1 七档怎么用

每题一句话，选它在多大程度上像你：

| 档位 | 记分 | 什么时候用 |
|---|---|---|
| 强烈不同意 | −3 | 基本不是我，甚至是我的反面 |
| 不同意 | −2 | 多数时候不是 |
| 有点不同意 | −1 | 略偏不是，但不好说 |
| 中立 | 0 | 真的两面都有，或者这题对我不适用 |
| 有点同意 | +1 | 略偏是 |
| 同意 | +2 | 多数时候是 |
| 强烈同意 | +3 | 几乎就是我 |

## 4.2 三条操作建议

**想「平时的你」，不想「你希望成为的样子」。** 这是自评量表最大的失真源。

**每题十秒内。** 想太久就开始推理「这题在测什么」，那时候答的是分析结果，不是你的实际反应。

**中间那档尽量别用。** 中立只用两种情形：真的两面都有，或者这题在你的生活里不存在（例如你没有合租过）。用它当「不想想」，会让你的分数整体向 50 挤，最后谁都不像。

## 4.3 152 题怎么分次做

可以在任意一题停下，进度存在这台设备上（同一浏览器）。建议分三次：第 1–50、51–100、101–152，每次十五分钟以内。中途不要回头改前面的答案——改的多半是「刚才那样答是不是显得我太怎么样」，那已经不是在答自己了。

# 第五章　怎么算

## 5.1 第一步：选项变成数字

七档直接对应 −3 到 +3，中间「中立」是 0。

## 5.2 第二步：反向题翻号

每 19 题里有 6 题是反向的。反向题的写法是把同一件事说成相反的说法，所以它的分数要翻号：你答 +3（强烈同意），在这一题上记 −3。

翻号之后，**每个功能方向上都是「分越高＝这个功能越强」**。

## 5.3 第三步：八个功能各求均值

每个功能 19 题，把 19 个数字取平均，得到一个 −3 到 +3 之间的数（记为 m）。再线性映射到 0–100：

**分数 = (m + 3) ÷ 6 × 100**

因为八个功能题数完全相等（都是 19 题），这八个 0–100 的分数**可以直接互相比**：Se 62 和 Te 48，就是 Te 比 Se 弱的意思。这是量表版相对二选一版最大的好处——二选一只能排相对高低，说不出「强多少」。

## 5.4 第四步：中心化（判类型用这一步）

绝对分有一问题：有人整体爱打高分，八个维度都在 70 以上；有人整体打低分，八个都在 30 以下。直接比绝对分，这两种人的类型判定都会被自己的作答风格带偏。

所以判类型用的是**个人内中心化**后的相对分：

**相对分 = 该功能分数 − 个人八维均值**

因为八维题数相等，这个减法是公平的。中心化之后，八个数字的和恒为 0，正数代表「比我自己其它功能更强」。

## 5.5 第五步：定主导，再定辅助

**主导＝相对分最高的那个功能。** 它决定你属于哪一种荣格类型（见第六章）。

**辅助＝在「另一类功能 × 相反态度」这两个候选里，相对分高的那个。**

这条规则是从荣格的结构推出来的：主导是外倾的，辅助就必须是内倾的；主导是知觉类（感觉/直觉），辅助就必须是判断类（思维/情感）。所以候选永远只有两个，不会更多。

例：主导是 Te（外倾思维，判断类），辅助候选就是「内倾知觉类」的两个——Si 和 Ni，取高的那个。

## 5.6 第六步：第三与劣势

第三和劣势不靠分数定，靠结构推：

- **第三＝与辅助同类、态度同主导**（也就是把辅助「翻」到另一个朝向）
- **劣势＝与主导同类、功能对立、态度相反**

用一张对照表最清楚（这张表就是程序里的 MAP）：

| 功能 | 对应的对立功能 |
|---|---|
| Te | Fi |
| Ti | Fe |
| Fe | Ti |
| Fi | Te |
| Se | Ni |
| Si | Ne |
| Ne | Si |
| Ni | Se |

**为什么不是简单地把态度翻一下。** 常见的错误做法是「辅助是 Ne（外倾直觉），那第三就是 Ni（内倾直觉）」——这只是把朝向翻了过去，功能还是直觉，不符合荣格的结构。正确的第三必须**换类**：辅助是 Ne（知觉类），第三就要在判断类里找，取与辅助功能对立、态度相同的那个，即 Ti。所以 Ne 辅助的 INTP，功能栈是 Ti-Ne-Si-Fe，不是 Ti-Ne-Ni-Te。

## 5.7 第七步：换成四字母

四字母只是为了方便和别人的说法对照，不是判定本身：

| 字母 | 从哪来 |
|---|---|
| E / I | 主导功能的朝向 |
| S / N | 主导或辅助里那个知觉类功能 |
| T / F | 主导或辅助里那个判断类功能 |
| J / P | 「对外展示的那个功能」属判断类还是知觉类：主导外倾就看主导，主导内倾就看辅助 |

**关于 J / P：** 这不是荣格的概念，是迈尔斯为了描述外部行为加的操作化约定。所以 **J ≠ 计划性强，P ≠ 散漫**。一个 J 型的人可能完全不做计划，因为他的 J 只是说明「对外展示的那个功能是判断类的」。这一点在 5.9 的例子和第八章都会再提。

## 5.8 第八步：置信度

结果页给两个数：

**领先幅度**＝第一名与第二名的相对分差（单位是分）。差 1 分以内的「第一名」基本没有意义。

**奇偶一致性**＝把 152 题按题号奇偶分成两半，各自算一套八维分，两套排序的斯皮尔曼相关系数。它衡量的是「你的答案前后一致吗」。一个人在认真作答时，两半应该给出相似的形状；如果差得远，说明后半段在敷衍、或者题目被猜到了。

| 置信度 | 条件 |
|---|---|
| 高 | 领先幅度 ≥ 6 分 且 一致性 ≥ 0.5 |
| 中 | 领先幅度 ≥ 3 分 且 一致性 ≥ 0.25 |
| 低 | 其余情况 |

置信度低不等于结果没用，它等于「这次作答不足以下结论」，最省事的做法是隔一周重做。

## 5.9 一个完整的例子（虚构）

| 功能 | 绝对分 | 相对分（减均值） |
|---|---|---|
| Te | 71 | **+17.5** |
| Ne | 62 | +8.5 |
| Se | 58 | +4.5 |
| Ni | 55 | +1.5 |
| Ti | 52 | −1.5 |
| Si | 46 | −7.5 |
| Fi | 44 | −9.5 |
| Fe | 40 | −13.5 |

八维均值 53.5。

1. **主导**：相对分最高是 Te（+17.5）。
2. **辅助**：Te 是判断类、外倾，所以候选是内倾知觉类——Si（−7.5）和 Ni（+1.5），取高者 → **Ni**。
3. **第三**：与辅助同类（知觉）、态度同主导（外倾）→ **Se**；也可以按 MAP：Ni 的对立面是 Se。
4. **劣势**：MAP[Te] = **Fi**。
5. **四字母**：主导 Te 外倾 → E；判断类主导 → T；知觉类辅助 Ni → N；对外展示的是 Te（判断类）→ J。得 **ENTJ**，功能栈 Te-Ni-Se-Fi。
6. **置信度**：领先幅度 17.5 − 8.5 = 9.0 分。若奇偶一致性 ≥ 0.5，判「高」。

注意这个例子里 Fe 只有 40 分——不是「这个人没有情感」，而是**在这一套描述里，他几乎不靠「照顾场面共识」来做判断**。分数低的是使用频率，不是能力。
